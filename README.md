# 🌍 Cube Effect Travel Slider

Этот проект представляет собой интерактивный слайдер туров с эффектом куба, созданный с использованием библиотеки [Swiper.js v11](https://swiperjs.com/) и оформленный через CSS-анимации и адаптивную верстку.

## 🔥 Функциональность

- 🎡 **Swiper-слайдер** с эффектом вращающегося куба
- 🌍 Четыре туристических направления с фото, ценами и рейтингами
- ⭐ Звездочный рейтинг с использованием `ion-icon`
- ✨ Красивый анимированный фон (`#tsparticles`, по умолчанию можно доработать)
- 📱 Полностью адаптивный дизайн
- 🚀 Готово для встраивания в любой туристический сайт или лендинг

## 📁 Структура проекта

```
.
├── index.html           # Главная HTML-страница
├── style.css            # Стили оформления слайдера и страницы
├── module.js            # Инициализация Swiper и дополнительных эффектов

````
