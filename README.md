# 🌍 Cube Effect Slider

Этот проект представляет собой интерактивный слайдер туров с эффектом куба, созданный с использованием библиотеки Swiper.

## 🔥 Функциональность

- 🌍 Четыре туристических направления
- 📱 Полностью адаптивный дизайн

## 📁 Структура проекта

```
├── index.html           # Главная HTML-страница
├── style.css            # Стили оформления слайдера и страницы
├── module.js            # Инициализация Swiper и дополнительных эффектов

````
